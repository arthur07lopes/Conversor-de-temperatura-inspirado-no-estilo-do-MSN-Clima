# Conversor-de-temperatura-inspirado-no-estilo-do-MSN-Clima
Este projeto foi realizado por Arthur Santos Lopes, aluno do curso de programador full-stack Jovem Aprendiz SENAI-RS Santa Cruz do Sul, onde foi feito um conversor de temperatura utilizando HTML, CSS e JavaScript.
O detalhe foi inspirado no site MSN Climas com o fundo de mistura de cores com detalhes em azul, branco e amarelho.
